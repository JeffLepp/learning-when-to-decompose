# WS3 — Router & evaluation library (manager brief, phase A)

Worker: **`codex`** (primary; use `codex2` if rate-limited). No GPU needed in this phase. Goal of phase A: a tested, label-format-agnostic routing/evaluation library implementing DESIGN_V2 §6, validated on v1 labels and on simulated labels with known ground truth. Then STOP and report.

## Tasks
1. **`v2/router/data.py`**: load `results/v2/labels/<domain>.csv` (§5 contract) into item × arm matrices (success, cost, seconds, logprob stats) per split; plus an adapter that converts the v1 runs (`results/train-8b-v1`, `validation-8b-v1`, `audit-8b-v1`) into the same contract (arms = qwen3:8b × {S0-direct, S3-decomposed}) so everything can be exercised now. Feature loaders for F1 (structural; generalize v1 `controller.py` features + ChainOps analogs via a hook), F2 (TF-IDF fit on train only), F3 (read `.npy` + `index.json`, align by id, assert order), F4 (post-hoc signals from labels).
2. **`v2/router/models.py`**: per-arm and shared (arm one-hot) success predictors — L2 logistic regression, HistGradientBoosting, small MLP; class-imbalance-safe (constant-label fallback); calibration (Platt/isotonic fitted on val); cost predictor.
3. **`v2/router/policies.py`**: fixed arms, best-single-arm (by val), cheapest-arm-meeting-target, heuristic rule (pluggable), predict-then-route with λ sweep (argmax p̂ − λ·cost) and v1 threshold rule, cascade over an ordered ladder with post-hoc confidence threshold τ (cost = sum of executed arms; must only use signals available at that point in the ladder), oracle (cheapest correct).
4. **`v2/router/evaluate.py`**: accuracy–cost curves (Pareto frontier of fixed arms; policy curves), normalized area under curve, accuracy-at-best-single-cost and cost-at-best-single-accuracy (interpolation documented), fraction of best-single→oracle gap closed, per-arm AUROC/Brier/ECE, learning curves over training-set size (repeated random subsamples), **paired bootstrap 95% CIs over items** for all policy differences, McNemar at operating points. All selection (λ, τ, threshold, layer, learner) on val only; a single `evaluate_on(split)` call computes test-split numbers from frozen choices and logs that it was called.
5. **`v2/router/plots.py`**: matplotlib figures (add matplotlib to `.venv` only if absent — ask orchestrator via status file before installing; meanwhile write plotting code and test it once approved): cost–accuracy plane with fixed arms, frontier, policy curves, oracle; reliability diagrams; learning curves; AUROC by feature family × model.
6. **Validation of the library itself**: (a) simulation test — generate synthetic items with a latent difficulty and arm-specific success curves where the optimal router is known analytically; check the learned router approaches it and that the cascade never uses unavailable signals; (b) run on v1 adapter data and reproduce the v1 controller-v1 audit numbers within the same config (logistic, threshold .5 → 15/32, 625.09 mean tokens) as a regression check; (c) unit tests in `v2/tests/test_router_*.py`.

## Stop and report
`managers/WS3_STATUS.md`: API summary, simulation-check results, v1 reproduction result, figure examples (paths), open design questions (e.g. how to charge probe overhead to cost).
